# Security Policy

## Supported Versions

The following versions of **JumpingSpider** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report vulnerabilities privately using one of the following methods:

1. **GitHub Private Vulnerability Reporting**: Open a security advisory on the [Security tab](https://github.com/Hailstone-Labs/JumpingSpider/security/advisories/new) of this repository.
2. **Email**: Contact the maintainer directly at `roger.allen795@gmail.com`.

Please include as much detail as possible:
- Type of issue (e.g., SSRF, path traversal, injection, dependency vulnerability)
- Steps required to reproduce the issue
- Affected version(s) and configuration
- Potential impact

You can expect an acknowledgment within 72 hours and updates as the issue is triaged and resolved.
